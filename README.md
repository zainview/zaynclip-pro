✨ Features
Feature	Details
♾ Unlimited History	Every copied text is saved automatically (unlimitedStorage)
⌨ Text Expander	Type ;sig → instantly expands into your full text
🧩 On-Page Widget	Alt+Shift+C — paste panel on any webpage
🪟 Floating Mode	Clipboard in a separate floating window
☁ Cloud Sync	Pinned clips + snippets via your Google account
🔒 Password Lock	SHA-256 passcode lock, auto-locks on restart
⚡ Advanced Shortcuts	5 pinned-paste shortcuts + widget + floating + lock
🔍 Smart Search	Instant filter, pin, delete, clear
💾 Backup	Full JSON export / import
🚀 Installation
Click Code → Download ZIP and extract it
Open chrome://extensions
Enable Developer mode (top-right)
Click Load unpacked → select the extracted folder
Done! Press Alt+Shift+V 🎉
⌨ Keyboard Shortcuts
Key	Action
Alt+Shift+V	Open popup
Alt+Shift+C	Toggle on-page widget
Alt+Shift+1 / 2	Paste pinned clip #1 / #2
Custom	Assign Floating, Lock & Fav 3–5 at chrome://extensions/shortcuts
🔐 Privacy
All data lives in your browser's storage.local — nothing leaves your device
Sync is optional and uses your own Google account's Chrome sync
Passcode is stored as a SHA-256 hash — the password itself is never saved
No analytics, no tracking, no external servers
🛠 Built With
Vanilla JavaScript — zero dependencies, zero frameworks
Chrome Extension Manifest V3
Shadow DOM for the isolated on-page widget
